# Nova2 + TG9801 固定高度垂直抓取

本技能使用外置相机的平面标定，将目标顶面中心像素映射到 User0/Tool0 的 XY；Z 固定为
标定首点的实际值。目标顶面四角必须来自与标定相同的去畸变彩色图像。所有长度为 **mm**、
角度为 **deg**，没有米制位姿参数。默认 VLM，另支持有本地 OBB 权重的 YOLO。

## 工具与参数

所有契约前缀为 `robonix/skill/nova2_grasp/`，返回 `ok/message/result_json`。
含字段的请求需要传完整字段；默认后端用空字符串 `backend=""`，不使用计划时 `plan_id=""`。

| 工具 | 参数 | 行为 |
|---|---|---|
| `status` | 无 | 读取标定、准备位、放置地点及释放高度、安装角、任务和本体反馈；不运动 |
| `detect_object` | `object:string, backend:string` | VLM/YOLO 顶面画框、中心、短轴、抓取/上方位姿、标注图和短期计划；不运动 |
| `plan_grasp` | `object:string, backend:string` | 识别后检查上方、对齐和抓取端点的控制器逆解。所有目标共用标定文件里的示教 Z |
| `approach` | `object:string, backend:string, plan_id:string` | **运动**：准备位→目标上方→短轴对齐，停在上方；不下降、不操作夹爪 |
| `pick` | 同 `approach` | 抓取后原地垂直抬升并保持夹持 |
| `pick_and_place` | 同 `pick`，另需 `destination:string` | 抓取抬升后运送到指定地点，在配置的释放高度松爪 |
| `cycle_from_hover` | 无 | **人工核对当前待夹位后**：张开→下降抓取→抬升→原位放回→松开→抬升→归位；不重新识别，保留当前 XY/Rz |
| `home` | 无 | **运动**：回到保存的准备关节位，不松爪；低位时先垂直抬升 |
| `release` | 无 | 仅在当前位置张开夹爪，可能释放手持物，不移动机械臂 |
| `stop` | 无 | 取消技能任务并停止机械臂，阻止后续步骤；不松爪、不自动回位 |
| `task_status` | 无 | 查看异步任务阶段、结果与失败原因 |
| `set_jaw_alignment` | `offset_deg:float64, confirmed:bool` | 仅保存两指闭合轴相对 Tool0 +X 的角度偏置，范围 ±180°；X=0，Y=90。旧视觉计划失效 |

`pick/pick_and_place/approach` 二选一提供 `object` 或当前会话未过期的 `plan_id`，另一个字段给空字符串。
`pick_and_place` 的 `destination` 填 `status.place_locations` 中的地点名，例如 `白盒子`。
`backend` 只能为 `vlm/yolo/""`；指定的后端失败时不隐式切换。YOLO 的类别名/别名需明确。
`detect_object/plan_grasp` 不会为了清空相机画面而自动回准备位。

## 运动与完成语义

`pick/pick_and_place/approach/cycle_from_hover/home/release` 立即返回 `RUNNING + run_id`。
必须重复查询 `task_status` 到 `SUCCEEDED/FAILED/CANCELED`。只有 `SUCCEEDED` 才代表所需步骤
经反馈确认；实际物体是否稳定保留仍需视觉或人工验收，设备 holding 并非视觉证明。

识别前根据末端反馈判断是否已在 `config/grasp/ready_pose.json` 中的准备位。需要回位时，
调用 `move_pose`（`MovJ`），确认到位后用新图像识别，再继续抓取。默认抓取停在取物点正上方并保持夹持。
准备位可以倾斜；抓取姿态为 `[Rx=180,Ry=0,Rz=求得角度]`，保持 Tool0 +Z 朝 User0 −Z。
到目标上方使用 MovJ。方向对齐、下降、抬升和放置过程使用 MovL。
放置沿用抓取姿态，在待夹位和释放位中的较高 Z 横移，到释放 Z 后松爪并停在释放位。
释放 Z 等于标定的 `z_mm` 加该地点的 `release_height_mm`。
各段必须确认到位后才开始下一段。当前速度 20%、用户授权上限 80%、上方距离 200 mm，可修改部署配置。

短轴由顶面四角映射到**机器人 XY 平面后**确定，不直接采用图像水平框宽/高；
两指沿较短轴相向闭合。近似正方形没有唯一短轴，允许两个等效方向，选择接近参考角的方向。
夹爪与法兰同轴且无偏心是本部署已确认的假设；不会计算旋转偏心补偿。

## 使用条件与失败处理

- 本技能通过 Atlas/MCP 调用现有 Nova2/TG9801 原语，不直接占用机器人 TCP 或夹爪串口。
- 图像由 `orbbec_camera` 原语通过 SDK/USB 采集，本技能经 Atlas/MCP 调用 snapshot；
  不依赖 8765 标定服务。启动本体会激活相机；旧标定程序/Viewer 须先退出以释放 USB。
- 机械臂必须已使能、退出拖动、静止、无报警，反馈与控制使用 User0/Tool0；不自动使能、清报警。
- 本机安装偏置为 −45°，对应俯视逆时针 45° 的补偿。更换安装后可用 `approach` 核对新的闭合方向。
- 夹爪已有稳定夹持、正在运动或有故障时，拒绝新的抓取，不自动松开原物体。
- 目标必须唯一、顶面可见、置信度达标且顶面中心在标定覆盖范围内。角点仅用于局部方向估计，
  不作为运动目标；顶面可以跨越覆盖边界。遮挡/多目标/普通水平框
  不能确定短轴时拒绝规划；不捏造位姿。
- 视觉计划默认 120 秒有效；相机模式不符、标定/准备文件变化或安装角变化时拒绝旧计划。
- 逆解只验证端点，不证明路径无碰撞或无奇异。首次真机测试先用 `approach` 核对。
- 失败后终止序列，并在已开始机械臂流程时请求停止；不自动换路径、重试、返回或松爪。
- 要停止完整抓取必须调用**技能 `stop`**。只停止底层机械臂不等于取消整个任务。
- TG9801 没有经验证的硬件停止命令：已经发出的夹爪动作可能完成，停止不会反向开合。
- `release` 只确认停止且非 holding，不能证明夹爪机械全开；夹持力百分比不是牛顿。

当前导入标定 7 点，最大训练拟合误差约 **19.35 mm**，部署允许上限为 20 mm。
该值不是独立验证精度。采用 5 cm 物体时，首次下落前需要核对上方中心对齐。
